# ほたるの夜 (Firefly Night)

夜の川辺でホタルを網でつかまえるアクションゲームです。`index.html` をブラウザで開くだけで遊べます(ビルド不要)。

## 遊び方
- 光っているホタルを網でつかまえると得点。消えている間は網をすり抜けます。
- 続けてつかまえるとコンボ倍率(最大×10)が上がります。
- 金色のホタルは50点。しばらくコウモリが遅くなります。
- コウモリに当たると灯がひとつ消え、3つ消えたらゲームオーバー。

## 操作
- マウス / タッチ:網がポインタを追いかけます
- キーボード:矢印キー・WASD、Enter / Space で開始
